

# 🍔 Recipe Explorer

**Recipe Explorer** is a clean, modern, and fully responsive web app that allows users to explore recipes from various cuisines around the world.  
It dynamically fetches recipe data from an external API and displays them in a beautiful grid layout with images, names, and cuisine details.

---

## 🌟 Features

- 📡 **Live API Integration** – Fetches real recipe data from [DummyJSON](https://dummyjson.com/recipes)
- 🍕 **Dynamic Recipe Cards** – Each card shows the recipe image, name, and cuisine
- 🔍 **Search Bar** – Quickly find recipes by name or keyword
- ❌ **Clear Button** – Reset search results with one click
- 📱 **Responsive Design** – Works perfectly on mobile, tablet, and desktop
- 🎨 **Modern UI** – Simple, elegant layout built with HTML, CSS, and JavaScript
- ⚡ **Fast and Lightweight** – No frameworks or dependencies required
